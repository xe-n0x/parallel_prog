# Лабораторная работа №1

## Тема

Последовательное умножение двух квадратных матриц на языке C++.

## Цель работы

Разработать и проверить программу для перемножения двух квадратных матриц, заданных во входных файлах. В ходе работы необходимо получить результирующую матрицу, измерить время выполнения программы и выполнить автоматизированную проверку результата с помощью сторонней библиотеки.

## Задание

Необходимо написать программу на языке C/C++ для перемножения двух квадратных матриц.

**Исходные данные:** файлы, содержащие значения исходных матриц.

**Выходные данные:** файл со значениями результирующей матрицы, временем выполнения и объёмом задачи.

**Дополнительное требование:** обязательная автоматизированная верификация результатов вычислений с помощью сторонних библиотек или стороннего программного обеспечения.

## Описание алгоритма

В программе используется классический последовательный алгоритм умножения матриц.

Пусть заданы две квадратные матрицы:

- `A` размера `N × N`;
- `B` размера `N × N`.

Результирующая матрица `C` также имеет размер `N × N`.

Каждый элемент результирующей матрицы вычисляется по формуле:

```text
C[i][j] = A[i][0] * B[0][j] + A[i][1] * B[1][j] + ... + A[i][N-1] * B[N-1][j]
```

В общем виде:

```text
C[i][j] = sum(A[i][k] * B[k][j]), где k = 0 ... N - 1
```

Алгоритм реализован с помощью трёх вложенных циклов:

```cpp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        for (int k = 0; k < p; k++) {
            C[i][j] += A[i][k] * B[k][j];
        }
    }
}
```

## Теоретическая сложность

Для каждой пары индексов `(i, j)` выполняется проход по индексу `k`.

Для квадратных матриц размера `N × N` количество итераций внутреннего цикла равно:

```text
N^3
```

Асимптотическая сложность алгоритма:

```text
O(N^3)
```

Если учитывать отдельно операции умножения и сложения, то приблизительное число арифметических операций можно оценить как:

```text
N^3 умножений + N^2 * (N - 1) сложений
```

или:

```text
2N^3 - N^2
```

## Анализ результатов

По результатам тестирования видно, что при увеличении размера матрицы время выполнения программы быстро возрастает. Это соответствует теоретической сложности классического алгоритма умножения матриц `O(N^3)`.

При увеличении размера матрицы с `200 × 200` до `400 × 400` размер `N` возрастает в 2 раза, а количество итераций внутреннего цикла увеличивается с `8 000 000` до `64 000 000`, то есть в 8 раз. Время выполнения при этом увеличилось со `119 ms` до `749 ms`, примерно в 6.3 раза.

При дальнейшем увеличении размера матриц наблюдается близкий к теоретическому рост времени: для `800 × 800` время составило `5.422` секунды, а для `1600 × 1600` — `43.765` секунды. Переход от `800` к `1600` также даёт увеличение размера `N` в 2 раза, а время выполнения выросло примерно в 8.1 раза.

Самый крупный тест `1600 × 1600` потребовал более четырёх миллиардов итераций внутреннего цикла.

## Вывод

В ходе лабораторной работы была разработана программа для последовательного умножения двух квадратных матриц на языке C++. Программа считывает исходные данные из файлов, выполняет умножение матриц, сохраняет результирующую матрицу и фиксирует время выполнения.

Для проверки корректности результата используется сторонняя библиотека NumPy. По результатам тестирования для матриц размеров `200 × 200`, `400 × 400`, `800 × 800` и `1600 × 1600` во всех случаях результат вычислений был подтверждён автоматической проверкой.

Полученные замеры показывают, что время выполнения растёт значительно при увеличении размера матриц, что соответствует сложности классического алгоритма `O(N^3)`. Последовательная версия программы может использоваться как базовая реализация для дальнейшего сравнения с параллельными версиями, реализованными с использованием OpenMP, MPI и CUDA.
